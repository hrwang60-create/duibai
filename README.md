# 对白（Duibai）—— 把文章，聊给你听

面向碎片时间（通勤、睡前、做家务）的听觉内容产品：把一篇文章的书面语，用指定口吻重构成两个人的口语对话，再由语音合成输出双音色音频。

核心用户流程：**上传文章 → 选择口吻 → 生成双人对话稿 → 确认可疑处 → 合成双音色音频 → 播放并逐句回看**。

## 目录

- `duibai-web/` —— **Web 实现**（Next.js 15 + React 19 + TypeScript + SQLite，分层架构）。
  接口清单、数据模型与模块划分依照《实验3：软件架构与界面设计》的设计基线落地。
  见 [`duibai-web/README.md`](duibai-web/README.md)。
- `期末作品/duibai-app/` —— 小程序实现（uni-app + uniCloud）。同一产品形态的另一端落地。
