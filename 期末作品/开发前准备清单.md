## 二、必须你去办（按紧急度排序）

### ★ 1. 微信小程序 AppID —— **唯一的关键路径，今天就办**

| 项 | 内容 |
| --- | --- |
| 入口 | https://mp.weixin.qq.com → 右上角「立即注册」→ 选 **小程序** |
| 要准备 | ① 一个**从未注册过**公众平台/开放平台、也未被个人微信号绑定的**邮箱**<br>② 身份证姓名 + 身份证号<br>③ 管理员手机号<br>④ **本人微信**（用于扫码做人脸识别） |
| 主体类型 | 选 **个人**（免费，够本作业用） |
| 耗时 | 填表约 5 分钟；**审核通常几小时到 1 天** |
| 拿到后 | 后台「开发管理 → 开发设置」复制 **AppID**（形如 `wx` 开头的一串） |

**个人主体的限制，对你有影响的只有一条**：不能开通微信支付。
本作业不涉及支付，**不影响**。另外同一身份证最多注册 5 个小程序，够用。

**⚠️ 两个能省掉大量时间的结论（我核实过）：**

1. **不需要备案。** 备案只在小程序「发布上线」时才要求。
   本作业只需要**录屏演示**，用开发版 / 体验版就够 → **完全跳过备案**（这是最慢的一环，能省掉）。
2. **开发阶段不必配域名白名单。** 微信开发者工具里勾选
   「**不校验合法域名、web-view、TLS 版本以及 HTTPS 证书**」即可直接请求任意域名。
   （报告里仍要写明：生产环境必须在小程序后台配置 request 合法域名，且须 HTTPS + 已备案。）

### 2. DCloud 账号（免费，2 分钟）

HBuilderX 需要登录它才能用 uniCloud。注册免费，直接在 HBuilderX 里登录即可。

### 3. uniCloud 服务空间 —— **选「阿里云版」**

**这是有依据的决策**：DCloud 官方定价文档写明，uniCloud 为每位开发者提供免费服务空间——
**阿里云版有 1 个免费空间，腾讯云版没有免费空间（必须付费购买套餐）**。

| 服务商 | 免费空间 | 对本作业 |
| --- | --- | --- |
| **阿里云版** | ✅ 有 1 个 | **选它**，零成本 |
| 腾讯云版 | ❌ 无，需付费 | 不建议 |
| 支付宝云 | ✅ 有 1 个 | 备选 |

阿里云版已知限制（对本项目无影响）：云存储不支持分目录、云存储单文件上限 100M。
我们要存的音频片段都是小文件，够用。

创建入口：HBuilderX → 登录后 → 左侧「uniCloud」→ 新建服务空间（选阿里云）。

## 六、安全提醒

- **AppSecret 绝对不能放进小程序代码**（AppID 可以公开，AppSecret 不行）。
  本项目的第三方密钥同理——**只在云函数的环境变量里**。
- 云数据库导出提交前（要求 3c），**必须把 `users` 表里的 openid 打码**。
