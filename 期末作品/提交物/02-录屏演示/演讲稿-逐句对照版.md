# 演讲稿 · 逐句对照版

> **原则：每一句话都有屏幕或动作承接。** 没有画面的句子我标了【述】，那是叙述不是证明 —— 少量是合理的，全篇都是「述」就等于没演示。
>
> **打点表读法**：左边念，右边做。念完一句，立刻做那个动作，中间不要停。

**标记**：`【证】` 屏幕上有东西证明它 · `【述】` 纯叙述，靠语气撑

## 出意外预案

| 情况 | 怎么办 |
| --- | --- |
| 确认页没出现可疑项 | 点「再生成一次」重来，最多 3 次；换篇 ② |
| 生成失败 | 说「网络不太好，我重试一次」→ 重投，**别跳过** |
| 音频没声 | 录前把系统音量开大；或只讲交互不播 |
| 点出处没反应 | 说「这里我用的是模拟环境」→ 切回继续 |
| 某句讲不顺 | **停，重录那一句**，别硬念 |
