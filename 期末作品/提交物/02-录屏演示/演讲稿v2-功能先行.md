# 演讲稿 v2 · 功能先行版

> **顺序：先演示 → 再讲前后端 → 最后看代码。**
> 理由：开场 40 秒就进演示，评委注意力最集中的时候不浪费在理念上；
> 而「创新点」放在演示之后，说服力是之前的几倍 —— **"你刚才看到的那个确认页，就是这么做的"**。
>
> **总时长 6 分 40 秒。**

## 录制顺序建议（省时间）

```
第一遍（试跑）  完整走一遍功能，确认页一定要出可疑项。不录。
第二遍（屏）  无声录屏：只操作，不说话。慢一点，确认页三个动作慢到位。
第三遍（音）  照稿念一遍语音（可以不看画面）。
第四遍（合）  剪映合成。哪里停顿不自然就补录那一句的语音。
```

## 出意外预案

| 情况 | 怎么办 |
| --- | --- |
| **确认页没出可疑项** | 点「再生成一次」，最多 3 次；换篇 ②。**这段是全片灵魂，别跳过** |
| 生成失败 | 说「网络不太好我重试一次」→ 重投，别慌着跳过 |
| 音频没声 | 录前开大系统音量；或只讲交互不播 |
| 点出处没反应 | 说「这里我用模拟环境」→ 切回继续 |
| 某句讲不顺 | **停，重录那一句**，别硬念 |
| 时间超了 | **砍段 3 的云函数逐个介绍**（留 `login` + `data` 两个），别砍演示 |
