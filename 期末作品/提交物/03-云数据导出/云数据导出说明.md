### 脱敏规则（重要）

所有 `openid`（微信用户唯一标识）已替换为：

```
MASKED_ + 原值前 3 位 + **** + 原值的 sha256 前 8 位
```

例如 `MASKED_oXk****3f9a2b71`。

**保留前 3 位，是为了让老师能看出几条记录属于同一个用户；
尾部哈希保证不可反推回真实 openid。**

导出文件中**不含任何密钥、token、口令**。

## 三、数据关系

```
users   1 ── n articles   1 ── n paragraphs
users   1 ── n scripts    1 ── n dialogue_lines   1 ── 1 audio_segments
tones   1 ── n scripts            （口吻模板直接决定生成质量）
banners / daily_episodes        （运营内容，客户端可直读）
```

### 出处回溯是靠外键实现的

`dialogue_lines.source_paragraph` → `paragraphs.seq`。

台词若标了 `source_paragraph: 0`，表示**这句话没有原文支撑**（模型自己加的），
前端会把它列进「可疑处」让用户确认。

**这就是「对话不是凭空编的」的机制保障** —— 每句话都能被追溯回原文，
追不到的必须由人点头才算数。

`audio_segments.file_id` 是**云存储的 https 直链**，可以直接打开试听：

```

```

把其中任意一条的 base64 解码，就是一个**标准 MP3 文件**（文件头 `494433` = ID3）。
