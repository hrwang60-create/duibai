> 走查维度（五轴）：① 触控目标 ② 三态（加载/空/错误）③ 按压反馈覆盖 ④ 无障碍(a11y) ⑤ 减动效

## 1. 🔴 必须改（建议立即返工）

### 🔴 1.1 对话流景深文字整体低于 AA（主屏，影响面最大）

**位置**
- `components/ConversationStream/ConversationStream.vue:232-238`（`.done/.next` 与 `.d1/.d2/.d3`）
- `components/ConversationStream/ConversationStream.vue:344-346`（`.dim` 态 opacity）
- 承载页：`pages/result/result.vue:608`（`.stage` 无底色 → 继承 `.page` = `$dui-page #EDE7D9`）、`pages/confirm/confirm.vue:378`

**实测（WCAG 相对亮度公式，底=页面纸 #EDE7D9）**

| 层 | 声明 | 合成后对比度 | AA(4.5:1) |
|---|---|---|---|
| 当前句 `.now` | `$dui-ink` / `$dui-vm` | 14.14 / 4.51（h1 大字） | ✅ |
| 已播 d1 | `ink4` + opacity .95 | **3.75** | ❌ |
| 已播 d2 | `ink4` + opacity .82 | **3.01** | ❌ |
| 已播 d3 | `ink4` + opacity .72 | **2.57** | ❌ |
| 未播 d1 | `ink3` + opacity .95 | **4.16** | ❌ |
| 未播 d2 | `ink3` + opacity .82 | **3.27** | ❌ |
| 未播 d3 | `ink3` + opacity .72 | **2.75** | ❌ |
| `dim` 态 d1/d2/d3 | `ink4` + .55/.48/.42 | 2.01 / 1.81 / 1.67 | ❌（暂停态，见下） |

**根因**：`done` 基色 `ink4 #756E61` 压**页面底**只有 **4.10**（<4.5）。`uni.scss:44-46` 对 ink4 的注释是「占位文字只出现在**卡片**上，实测卡片底 4.51:1」——**卡片底成立，页面底不成立**；而对话流恰恰在页面底。再叠 opacity，进一步跌破。

**修法（保留景深、不引入新产品决策）**
1. 两档景深改色：`done → $dui-ink3`（页面底 **4.55** ✅）、`next → $dui-ink2`（页面底 **5.85** ✅）；保留 `.now = $dui-ink`。
2. **去掉文字上的 opacity 下限**（0.72 会破标），景深改由**字号 + 位置 + 竖轨**承担——`.d1/.d2/.d3` 的字号阶梯（body→caption→label）本就足以表达「越远越轻」。
3. 若产品坚持留一点透明度做氛围：上限设 `opacity ≥ 1.0` 用于文字层，把透明度只留给**竖轨/点**这类装饰（`ink5` 做装饰是合规的）。
4. `dim` 态（confirm 页"谈话被打断"）文字同样按上表改；它的低对比只在"内容已在 SuspectCard 复述"的语境下可被原谅，但**不应低于 3:1**。

> 备注：这条是主屏的核心观感所在，改色后**整体纸墨观感不变**（色相不动，仅明度阶梯从 ink4/ink3 抬到 ink3/ink2），视觉上仍是一段"渐隐的谈话"。

### 🔴 1.2 首页「今日一集」的「往期 →」链接 3.01:1

**位置** `components/DailyCard/DailyCard.vue:223-228`（`.act-dim { color:$dui-vm; opacity:0.7 }`）

**实测** `$dui-vm #B83F28` @0.7 压卡片底 → 合成 `#CA7562` = **3.01:1**（<4.5）；压页面底 = **2.85**。

**修法**：删掉 `opacity:0.7`（回到 `$dui-vm` = 4.97 ✅）；若要维持"次级"层级，用 `$dui-ink2`（6.44）或缩字号，**不要用降透明度**——降透明度会把已达标的朱一起拖垮。

### 🔴 1.3 UploadCard 工具胶囊触控高仅 68rpx

**位置** `components/UploadCard/UploadCard.vue:157-166`（`.tool { height:68rpx }`）

**修法** `height: 88rpx`（或挂全局 `.tap-88`）。

### 🔴 1.4 「今日一集」两个动作触控高不足

**位置** `components/DailyCard/DailyCard.vue:213-221`（`.act`）、`:223-228`（`.act-dim`）、`:205-211`（`.acts`）
**实测** `.act/.act-dim` 均**无显式高度**，行高由内容决定（20px svg / 27rpx 文本）≈ **40rpx** < 88rpx。命中「▶ 听整集」「往期 →」。
**修法** `.acts` 行或 `.act` 加 `min-height: 88rpx`。
