## 一、A1 首页 · 默认态

文件：`pages/index/index.vue`　tab 页

| # | 元素 | 内容 | 交互 / 跳转 |
| --- | --- | --- | --- |
| ① | 品牌行 | 左「对白」，右「我的」 | 点「我的」→ 切到「我的」tab |
| ② | 主张 | 「把文章，聊给你听。」 | 静态。**Display 字号，是首页最大字** |
| ③ | **今日一集** | 朱色顶边 +「今日一集」标签 + 集标题 + 「口吻 · 时长 · 句数」+ **3 句对话预览**（中间句高亮） | 【▶ 开始听】→ 进【结果 A5】以 episode 模式播放；【往期 ›】→ 进【每日一集】页 |
| ④ | 主操作 | 「＋ 投一篇文章」 | 点 → **首页原地展开为输入态（A2）**，不跳页 |
| ⑤ | 最近 | 最近 2 条：标题 + 口吻 · 句数 | 点条目 → 直接进【结果 A5】（带 `script_id`）。**不放完整历史** |
| ⑥ | 底部 tab | 对白（选中）/ 历史 / 我的 | switchTab |

> **③ 替代了原设计的「示例对谈」块 —— 一块兼两用。**
> 原来的示例是**假内容**（只为了演示）；现在直接用**今天的真实一集**：
> 既让用户 3 秒看懂"这是把文章变成两人对谈"，又是**当天可听的内容**。
> 首页反而更简洁：从 6 块减到 5 块。

**为什么③是首屏主视觉**：产品最大的创新是"两个人聊"，把它放在首屏直接演出来，比任何文案都有说服力。**示例即教程，所以不需要额外的新手引导层。**

前端组件：`DuiBanner` 已废弃 → 改为 **`DemoDialogue`**（自动推进的示例对谈）

## 二、A2 首页 · 输入展开态

同文件，`expanded: true` 状态。**不单独做页面**，避免用户迷路。

| # | 元素 | 内容 | 交互 / 跳转 |
| --- | --- | --- | --- |
| ① | 收起 | 「← 收起」 | 回到 A1 默认态 |
| ② | 粘贴区 | 大 textarea，placeholder「粘贴文章内容…」 | 输入即统计字数 |
| ③ | 文件入口 | 「选择文件」/「从聊天选」 | 微信端用 `uni.chooseMessageFile`；其他端提示直接粘贴 |
| ④ | 内容反馈 | 「3280 字 · 预计约 4 分钟」 | 实时更新。字数超限时变警示色并禁用⑦ |
| ⑤ | 口吻选择 | 6 个胶囊：抬杠讨论 / 轻松解释 / 朋友聊天 / 新闻播客 / 严谨讲解 / 课堂讨论 | 单选。数据来自 `tones` 表 |
| ⑥ | **口吻预览** | 选中口吻后**立刻显示该口吻的一句示例** | **这是关键设计**：用户选口吻时就已经看到产品能力，不用等生成 |
| ⑦ | 主按钮 | 「**开始聊**」（不写"开始生成"） | 点 → 校验：未登录则跳【登录 B1】；通过则调 `data.article.add` → 成功跳【生成中 A3】 |

**文案原则**：用「开始聊」而不是「开始生成」——"生成"是技术语言，用户做的事是"让它开始聊"。

## 四、A4 确认（可疑处让对话「卡住」）

文件：`pages/confirm/confirm.vue`

| # | 元素 | 内容 | 交互 / 跳转 |
| --- | --- | --- | --- |
| ① | 顶部 | 「有 3 处需要你确认」+ 右侧「1 / 3」 | 静态 |
| ② | 可疑卡片 | `?` 图标 + 「可能的问题」+ 说明：「原文说的是『类囊体薄膜』，台词写成了『叶绿体基质』」 | **不要写成"⚠️ 第 12 句存在问题"** —— 那太像表单 |
| ③ | 原文对照 | 卡片内直接给出原文片段 | **不让你凭记忆判断** |
| ④ | 三个动作 | 「查看原文」/「修改这一句」/ 「确认没问题」 | 查看原文 → 跳【原文 B3】；修改 → 就地编辑；确认 → 调 `line.confirm` |
| ⑤ | 对话流 | 卡片上下各一段灰字对话，**整体变暗** | 表示"对话停在这里" |
| ⑥ | 停住提示 | 「对话停在这里 —— 回应之后才继续」 | 静态 |
| ⑦ | 底部主按钮 | 「全部确认，开始生成声音」 | **仍有未确认项时禁用**（后端返回 409）；全部确认后 → 调 `tts-synthesize` → 跳【结果 A5】 |

**这是产品第二个记忆点**：把"审核 AI 输出"从表单变成**对话剧情节点**。

## 五、A5 结果（对话流，**70% 设计精力在这页**）

文件：`pages/result/result.vue`

| # | 元素 | 内容 | 交互 / 跳转 |
| --- | --- | --- | --- |
| ① | 顶部 | 「← 光合作用到底怎么回事」+ 右侧「⋯」 | 「⋯」→ 导出文字稿 / 换口吻重新生成 |
| ② | **对话流** | 当前句**居中、最大（36rpx+）、最亮**；上下句带**景深**（更小、更淡、更靠边）；左**甲墨色 / 乙朱色**，靠**字的颜色**区分，**不用头像不用气泡** | 点任意一句 → **该句浮到中央并重播** |
| ③ | 进度轨 | 左侧细竖轨 + 一个点 | **点的位置 = 说到第几句**。不是进度条 |
| ④ | 出处 | 「出处 P3」可点 | 点 → 跳【原文 B3】并高亮该段 |
| ⑤ | 改这句 | 「改这句」 | 就地编辑该句（走 `line.update`） |
| ⑥ | 重做入口 | 「这里听不清？重新聊」 | 点 → **弹出底部浮层 F1** |
| ⑦ | 播放控制 | 倍速（0.8/1.0/1.25/1.5）+ 上一句 / 播放 / 下一句 | **刻意做小、靠底** —— 播放器是辅助，对话流才是主体 |

**核心判断：视觉上彻底放弃 `AudioPlayer + LyricSync` 的播放器范式。**
组件命名 `LyricSync` **废弃** → 改为 **`ConversationStream`**（它不是"歌词同步"，是主界面）。

## 十五、补充页：每日一集

文件：`pages/daily/daily.vue`　（新增，第 14 个页面）

### 为什么加这一块

「对白」有个**冷启动硬伤**：新用户进来没有自己的文章，首页就是空的，**没事可做**。
「每日一集」直接解决它 —— **不用上传，打开就有得听**。

它同时给了用户**每天回来的理由**，对留存和演示观感都重要。

### 页面元素

| # | 元素 | 内容 | 交互 / 跳转 |
| --- | --- | --- | --- |
| ① | 顶部 | 「← 返回」+ 「每日一集」 | 返回上一页 |
| ② | 今日大卡 | 朱色顶边 +「今日 · 10月3日」+ 集标题 + 2 句预览 + 「▶ 开始听」 | 点 → 进【结果 A5】以 episode 模式播放 |
| ③ | 往期列表 | 每行：日期 + 集标题 + 时长 | 点 → 进【结果 A5】听该集 |
| ④ | 底部说明 | 「每天一集，不用你上传，打开就能听。」 | 静态 |

### ⚠️ 关键技术约束：**绝不能用定时任务生成**

uniCloud 按「**单个函数 + 小时**」计费，某函数某小时内只要有消耗就**至少折算约 90 GBs**；
阿里云免费额度仅 **1000 GBs/月 ≈ 11 个函数小时**，**超出直接停服**。

> **若用「定时任务云函数每天自动生成一集」→ 一个月 30 个函数小时 → 必然超额停服。**

**正确做法：离线预置内容，客户端直接读，云函数调用 = 0。**

| | 定时任务实时生成 ❌ | **离线预置 ✅** |
| --- | --- | --- |
| 云函数消耗 | 30 小时/月 → **停服** | **0** |
| 内容质量 | 每天自动生成，不可控 | 可人工挑选、校对 |
| 专业度 | 像 Demo | **像真正的内容运营** |

### 数据设计：新增集合 `daily_episodes`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `date_key` | int | 如 `20261003`，用于按日期取当天那集 |
| `title` | string | 集标题 |
| `source_title` | string | 取材于哪篇文章 |
| `source_text` | string | 原文（供出处回溯） |
| `tone_code` | string | 口吻 |
| `duration_sec` | int | 时长（秒） |
| `lines` | array | 预置好的对话条目 `[{speaker, text, source_paragraph}]` |
| `audio_file_id` | string | 云存储音频 fileID（TTS 接上后补） |
| `enabled` | bool | 是否上架 |

**权限**：客户端**可读**（不必过云函数，省一次调用）。

**取用规则**：客户端按今天的 `date_key` 精确匹配；没有则取**日期最大的已上架一集**（保证永远有内容）。

**内容来源**：
- 第一期准备 **7 集**（一周循环），之后可续
- 音频等 TTS 接上后**一次性批量离线合成**，存云存储
- ⚠️ **不依赖任何 Key 也能先做** —— `lines` 是纯数据，我直接写进 `db_init.json`
